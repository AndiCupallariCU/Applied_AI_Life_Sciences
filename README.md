# Applied AI in Life Sciences — Fall 2026

Course materials for the Columbia University Data Science Institute master's course
Applied AI in Life Sciences.

Each `Week NN - …` folder contains the slides (.pptx), student handouts (.docx), notebooks (.ipynb),
synthetic datasets (`data/`), PDF exports (`pdfs/`) and the reading assignment (`reading assignment/`).
All datasets are synthetic; GLUCOREN and the other brands are fictional.


## Running the notebooks
```
pip install pandas duckdb matplotlib jupyter
cd "Week 02 - Pharma Datasets and Claims Analytics"
jupyter lab
```
